# ☕ Cravings Cafe

A modern and responsive cafe website built to provide a clean, attractive, and user-friendly online experience for customers.

🔗 **Live Demo:** https://nishan75.github.io/Cravings-Cafe/

🔗 **GitHub Repository:** https://github.com/NISHAN75/Cravings-Cafe

---

## 📌 About The Project

**Cravings Cafe** is a responsive cafe website designed with a modern UI and smooth user experience.

The project focuses on creating an attractive cafe website that works seamlessly across desktop, tablet, and mobile devices.

It includes sections for showcasing the cafe, menu items, services, special offers, and other important information.

## ⚙️ How To Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/NISHAN75/Cravings-Cafe.git
```

### 2. Open the project

```bash
cd Cravings-Cafe
```

### 3. Run the project

Simply open `index.html` in your browser.

For the best development experience, you can use the **Live Server** extension in VS Code.
